Backup

Archives your config ({{ config_dir }}) and state ({{ state_dir }} — the database, face models and other review state) into one file, named with the date and the psort commit that made it, so you can tell which version of psort it came from. Thumbnail, face-crop and poster caches are skipped by default (they're regenerated automatically); tick below to include them anyway. This isn't a substitute for backing up the library itself.

Existing backups

To restore (or move to a new computer), close this page's server and run uv run psort restore <archive> --relocate in a terminal. It can't be done from here: a restore replaces the database this page is using.
